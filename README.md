# 🏕️ YelpCamp – Campground Review Web App

YelpCamp is a full-stack **Node.js + Express + MongoDB** web application using **EJS templates**.  
This was my **first major web development project**, built while learning from **Colt Steele’s Web Developer Bootcamp** and later improved with extra features like **MapTiler maps**, **multiple images**, **authorization**, and a **reviews system**.

# ✨ Features

### 👤 Authentication  
- Manual **username + password** login/register  
- Session-based authentication  
- Secure password hashing  
- Flash messages for feedback  

### 🏕️ Campgrounds  
Logged-in users can:
- Create campgrounds  
- Add **multiple images**  
- Add **location, price, title, and description**  
- View all campgrounds  
- View detailed campground page

### 🔒 Authorization  
Only the **creator** of a campground can:
- Edit it  
- Delete it  

Protects against unauthorized modifications.

### 📍 Interactive Map (MapTiler)  
- Each campground shows on an interactive **MapTiler** map  
- Map popup includes title & location  
- Smooth zoom & navigation  

### ⭐ Reviews  
Logged-in users can:
- Add **star ratings (1–5)**  
- Add a **written review/comment**  
- View reviews on campground page
- Delete their reviews
